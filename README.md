A one-line joke about office life for make.fun's One-Line Office Joke: 24-Hour Sprint. The program writes a single line — a 15-minute "quick sync" that somehow needs a pre-meeting, a follow-up, and a meeting to discuss the meeting — to `/output/entry.txt`.

## How it works

`main.py` validates the line (one line, 1–200 characters, not blank), writes it with a single trailing newline, then reads the file back and confirms it holds exactly the validated line and nothing else.

```sh
python3 main.py
```

Set `OUTPUT_PATH` to write somewhere else (the grader uses `/output/entry.txt`).
